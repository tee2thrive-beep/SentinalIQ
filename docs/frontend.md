# SentinelIQ — SOC Analyst Dashboard & Frontend Investigation Console Documentation

## 1. Overview & Architecture

The **SentinelIQ SOC Analyst Dashboard & Investigation Console** (`frontend/`) is a production-quality web application built with React, Vite, TypeScript, Tailwind CSS, Recharts, and Lucide React icons.

```
┌─────────────────────────────────────────────────────────────┐
│                 FastAPI Backend REST API                    │
│                 (http://localhost:8000/api)                 │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│                Centralized API Client Layer                 │
│                 (frontend/src/services/api.ts)              │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│             SOC Frontend Router & Workspaces                │
│                                                             │
│ ├── Dashboard (/)         : Summary Cards & Donut Charts    │
│ ├── Priority Queue        : Ranked 1..111 Table & Filters   │
│ ├── Investigation Console : Six-Factor Math, Timeline,      │
│ │                           Correlations & Recommendations  │
│ ├── What-If Simulations   : Scenario Movers & Sensitivity   │
│ ├── Reports               : JSON & Rendered Markdown Viewer │
│ └── System Status         : Live Engine Health & Latency    │
└─────────────────────────────────────────────────────────────┘
```

## 2. Page Breakdown

### A. Dashboard Page (`/`)
- **Metric Cards**: Total Incidents (`111`), Critical (`9`), High (`39`), Medium (`57`), Low (`6`), Highest Score (`90.20`), Average Score (`47.11`).
- **Risk Level Distribution**: Recharts Donut Pie Chart & Vertical Bar Chart.
- **Top Priority Incident Banner**: Quick navigation to Rank #1 incident (`INC-0021`).

### B. Priority Queue Page (`/incidents`)
- **Ranked Queue Table**: Displays incidents in exact Step 6 priority rank order ($1..111$).
- **Interactive Controls**: Risk level filter (`CRITICAL`, `HIGH`, `MEDIUM`, `LOW`), Incident type filter, Search by incident ID or type, Pagination (`15` items/page).
- **Action**: "Investigate →" direct route to analyst workspace.

### C. Incident Investigation Console (`/incidents/:incidentId`)
- **Top Summary Header**: Priority rank badge, Risk Score ($0–100$), Risk Level badge, Alert count, User count, Time bounds.
- **Executive Summary Card**: Canonical natural language summary generated by Step 8 engine.
- **Six-Factor Risk Score Breakdown (`RiskMathCard`)**: Detailed math table ($R = 0.20S + 0.20A + 0.10U + 0.15D + 0.15C + 0.20B$), weighted contribution bar chart, dominant risk drivers.
- **Priority Queue Ranking Explanation**: Explains why the incident outranks the next item in the queue and details tie-breaker rules.
- **Chronological Attack Timeline (`TimelineCard`)**: Chronologically ordered events with resolved asset names, usernames, IPs, and severity markers.
- **Multi-Signal Correlation Evidence (`CorrelationCards`)**: Correlated alert pairs, matched signals, temporal proximity, and evidence summaries.
- **Attack Progression Stage Pipeline (`ProgressionCard`)**: Visual MITRE ATT&CK kill chain pipeline stages (Initial Access $\rightarrow$ Execution $\rightarrow$ Privilege Escalation $\rightarrow$ Lateral Movement $\rightarrow$ Exfiltration).
- **Affected Asset & User Context**: Asset criticality, business impact, data sensitivity, user role, department, privilege level.
- **Automated Policy Recommendations (`RecommendationsCard`)**: Suggested investigation and containment actions explicitly flagged as policy guidance.

### D. What-If Simulation Page (`/simulations`)
- **Scenario Tabs**: `baseline`, `user_impact_focus`, `data_protection_focus`, `business_continuity_focus`, `high_confidence_focus`.
- **Top Movers Tables**: Displays top upward and downward rank movers with `rank_change` and `score_delta`.
- **Factor Sensitivity Ranking Chart**: Recharts bar chart displaying factor influence scores (`Attack Confidence` #1 most influential factor).

### E. Reports Page (`/reports`)
- Searchable index of generated investigation reports.
- Modal viewer supporting toggles between **Canonical JSON** and **Rendered Summary** formats.

### F. System Status Page (`/status`)
- Live API health indicator (`GET /api/health`), response latency (ms), engine version (`1.0`), and data lineage checklist.
